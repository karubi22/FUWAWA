# Raora Panthera「Jacket off」同人 Live2D 前期制作规格

版本：0.1  
日期：2026-11-17  
用途：立绘重绘、PSD 拆分、Live2D Cubism 绑定及 VTube Studio 调试的制作交接。

> 本文件是前期制作规格，不是官方模型，也不是已分层 PSD、`.cmo3` 或 `.moc3`。当前样本是四合一低分辨率参考图，不能直接裁切放大为可绑定立绘。

## 1. 制作范围

### 1.1 基础版本（P0）

- 正面全身模型，以样本最左侧 **Jacket off** 造型为唯一服装基准。
- 保留：贝雷帽、猫耳、圆框眼镜、两侧发夹、粉色长卷发、双麻花辫、发尾蝴蝶结、项圈、胸前大蝴蝶结、白色短袖衬衫、蓝色格纹百褶裙、腰带与挂饰、单侧腿环、白色堆堆袜、黑色厚底鞋、尾巴。
- 不包含外套和围巾，不在基础版本中预留这些服装的共用图层。
- 基础动作：头部 XYZ、视线 XY、双眼眨眼、眉毛、嘴部开合与口型、轻微身体摆动、呼吸。
- 基础物理：前发、侧发、后发、左右麻花辫、裙摆、胸前蝴蝶结、尾巴、腰部挂饰。
- 手臂仅做轻微跟随与惯性，不做手部捕捉、手指跟踪或独立手势系统。

### 1.2 可选增量（P1／P2）

- P1：眼镜、帽子、腰部挂饰的显示开关；脸红和微笑表情快捷键。
- P2：独立手臂姿势、手持物、额外口型、外套与围巾差分。以上均需另行补画和绑定。

## 2. 视觉基准

- 发型：粉色长卷发，后半部发量充足；左右各一条长麻花辫，发尾系大型玫红色蝴蝶结。画面右侧有明显浅白挑染。
- 头部：粉色猫耳配白色内耳，深色贝雷帽位于猫耳后方；金色眼睛、黑色圆框眼镜，左右发夹不对称。
- 上身：白色短袖衬衫、灰色领口、玫红色大蝴蝶结、黑色项圈及小吊坠。
- 腰部：深色腰带、银色心形扣、链条和多个彩色小挂饰。所有挂饰应与腰带和裙子分层。
- 下身：蓝色格纹百褶裙；画面右腿可见粉色腿环与吊袜带。腿部、腿环和吊袜带不得合并。
- 手臂：按样本保留不对称袖套与腕饰。画面左侧小臂有白色针织袖套；画面右侧手腕有玫红色发圈。
- 脚部：白色宽松堆堆袜、外侧小蝴蝶结、黑色厚底搭扣鞋。
- 尾巴：粉色带深色斑纹，从身体后方绕出；尾根必须补画，尾巴与后发、腿部完全分层。

## 3. 立绘与 PSD 要求

- 建议画布：**4500 × 7000 px、RGB、8 bit、透明背景**。300 dpi 仅作为印刷元数据，不影响 Live2D 运行。
- 人物占画布高度约 85%–90%，四周给头部转动、辫子、尾巴和手臂变形预留空间。
- 只保留一个完整人物，不带 `jacket off` 等文字，不带白底，不保留其他三套造型。
- 采用正面、轻微 A-pose；左右手臂与躯干之间留出可拆分间隙，手指不需要单独分层。
- 每个独立运动部件单独命名。部件内部的线稿、底色、阴影可合并；不同运动部件不得共用线稿或阴影。
- 被遮挡区域必须补全，不允许仅沿可见轮廓抠图。活动边缘建议至少外扩 20–40 px，避免转头或物理摆动时露白。
- 不使用跨图层的整体渐变、整体投影或统一环境光。阴影应随所属部件运动。
- 格纹先保证单裙片连续，再分裙片；不要在拆分时破坏格纹走向。
- 最终导入 Cubism 前合并不必要的装饰子层，但不得合并眼睛、嘴、眉毛、眼镜等独立控制部件。

详细图层见 `Raora_JacketOff_Layer_Map.csv`。表中顺序为由后至前，模型师可根据实际遮挡微调。除特别说明外，图层命名中的 L／R 均指**画面左／右**，并非角色自身左右；若改用角色自身左右，应统一重命名。

## 4. 必须补画的区域（P0）

### 4.1 头部与头发

1. 前发下方的完整额头、眉毛、眼睑和皮肤。
2. 眼镜下方的完整眼睛；镜片不能只保留当前可见的反光区域。
3. 眼白、虹膜、瞳孔和高光需完整绘制，闭眼后不得残留眼球或睫毛。
4. 猫耳、帽子和侧发下方的头发与头部轮廓。
5. 后发被颈部、衬衫、手臂和腰部遮挡的部分。
6. 麻花辫各段的完整截面，以及蝴蝶结下方的辫尾。

### 4.2 躯干与服装

1. 下巴下方的完整颈部，项圈下方的颈部皮肤。
2. 胸前蝴蝶结下方的衬衫、领口和纽扣。
3. 袖子下方的完整上臂轮廓；袖套和发圈下方的手腕。
4. 衬衫下摆被腰带、裙头遮挡的部分。
5. 腰带、心形扣、链条和挂饰下方的裙头及裙片。
6. 裙子下方的完整大腿上部；腿环和吊袜带下方的皮肤。
7. 堆堆袜上方的小腿，以及鞋口内部的脚部衔接。

### 4.3 尾巴与配件

1. 尾根及其被臀部、裙子、后发遮挡的部分。
2. 尾巴各活动段被前一段遮挡的截面。
3. 所有挂饰的完整轮廓和连接环，避免摆动时出现断链。

## 6. Cubism 绑定结构

建议变形器层级：

```text
Root
├─ Body_Position
│  ├─ Lower_Body
│  │  ├─ Skirt_Physics
│  │  └─ Tail_Rotation > Tail_Physics
│  ├─ Torso > Breath
│  │  ├─ Arm_L / Arm_R
│  │  ├─ Chest_Bow_Physics
│  │  └─ Head_XYZ
│  │     ├─ Face_XY
│  │     │  ├─ Eye_L / Eye_R > Iris_L / Iris_R
│  │     │  ├─ Brow_L / Brow_R
│  │     │  └─ Mouth
│  │     ├─ Hair_Front_Physics
│  │     ├─ Hair_Side_L / Hair_Side_R
│  │     └─ Hat_Ears_Glasses
│  └─ Hair_Back_Physics
└─ Braid_L_Physics / Braid_R_Physics
```

- 头部 XY 使用关键点插值，Z 轴单独处理旋转，避免只旋转整张脸。
- 眼球移动需限制在眼睑内，虹膜、瞳孔和高光共用遮罩。
- 嘴部至少包含闭嘴、微张、张嘴、微笑和抿嘴状态；口腔、牙齿和舌头独立于嘴唇。
- 身体角度变化不应带动脚底明显滑出取景区域。
- 发辫与尾巴采用分段变形，不做整根刚性旋转。

参数清单见 `Raora_JacketOff_Parameters.csv`。该 CSV 是制作规格，不能直接导入 Cubism 或 VTube Studio。

## 7. 物理组建议

| 物理组 | 主要输入 | 主要输出 | 注意事项 |
|---|---|---|---|
| 前发 | AngleX／Y／Z | ParamHairFront | 摆动幅度小，不能露出额头缺口 |
| 左右侧发 | AngleY／Z | ParamHairSideL／R | 两侧允许不对称 |
| 后发 | BodyAngleX／Z | ParamHairBack | 大质量、低频率，避免穿过躯干 |
| 左右麻花辫 | AngleZ、身体移动 | ParamBraidL／R | 至少三段，发尾蝴蝶结随末段运动 |
| 裙摆 | BodyAngleX／Z | ParamSkirt | 保持格纹连续，避免露出腿根缺口 |
| 胸前蝴蝶结 | AngleZ、呼吸 | ParamBow | 结心与飘带分开，结心幅度较小 |
| 腰部挂饰 | BodyAngleZ | ParamCharms | 链条与挂饰可分组，避免集体同向摆动 |
| 尾巴 | BodyAngleZ、头部移动 | ParamTail | 至少四段，延迟逐级增加 |

## 8. 表情与开关

### P0 表情

- 默认、微笑、开心闭眼、轻微惊讶。
- 眨眼由跟踪参数控制，不应被固定表情覆盖。

### P1 快捷键

- 眼镜显示／隐藏。
- 帽子显示／隐藏。
- 腰部挂饰显示／隐藏。
- 脸红显示／隐藏。

切换显示对象时，必须同时检查遮挡关系；例如隐藏眼镜后仍应保留完整眼睛和眉毛。

## 9. VTube Studio 接入与验收

### 基础接入

- 头部 XYZ、双眼开合、眼球 XY、眉毛、嘴部开合和口型映射到对应跟踪输入。
- `ParamMouthOpenY` 可映射麦克风音量或面部跟踪张嘴输入，正式使用时避免两个输入相互抢值。
- 呼吸使用自动循环；物理组在模型静止时仍应自然回稳。
- 模型默认取景可采用半身，但交付源文件保留全身。

### 验收清单

- 头部达到设定 XYZ 极值时，发际、颈部、猫耳和眼镜无明显裂缝。
- 双眼完全闭合时无眼球、眼白或高光残留。
- 眼球移动到四角时不越出眼睑遮罩。
- 张嘴与微笑组合时无双层嘴唇、漂浮牙齿或口腔穿帮。
- 辫子、裙摆和尾巴物理摆动时不穿过身体或出现断层。
- 关闭眼镜、帽子或挂饰后，下方补画完整。
- 连续运行后模型能回到默认姿态，无持续漂移。
- 交付模型在目标设备的 VTube Studio 中实际加载并检查跟踪、热键和物理。

## 11. 继续制作所需素材

当前四合一参考图足以确定造型，但不足以制作高质量分层立绘。下一步需要以下二选一：

1. **优先：**提供 Jacket off 的单人高清原图或已有 PSD；或
2. **重绘：**以当前样本为参考，先完成一张完整单人立绘，再按图层表补画和拆分。

若只有当前样本，不能把自动抠图或无损放大称为完成 Live2D 分层。涉及同人发布或商业使用时，还需另行核对 hololive production 最新二次创作指南及使用范围。
